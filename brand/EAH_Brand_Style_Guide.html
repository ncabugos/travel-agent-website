Primary Typeface — Marketing & Brand

Headlines

Websites for Elite Travel Advisors

Live site renders the system UI font (San Francisco on Apple, Segoe UI on Windows, Roboto on Android). For brand docs use Inter as the embeddable equivalent. Weight 800, tracking -0.03em.

Body & UI

A website platform for independent travel advisors and boutique agencies. A curated network of luxury hotels and cruise lines, kept current for you.

System UI / Inter. Weights 400–600.

Why Inter? The marketing site uses the OS system font, which cannot be embedded in decks, PDFs, or Canva, and Apple’s SF Pro license forbids marketing use. Inter (SIL Open Font License, free) is the closest match. Document it as the brand font everywhere a file needs an actual embedded typeface.
