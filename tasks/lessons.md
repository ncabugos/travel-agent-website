# Lessons

## 2026-08-31 — Check `memory/` voice rules before writing any marketing copy

**What happened:** Wrote "The houses that took to sea" as a section heading on /yachts and
"The Houses" as a section label on /experiences. The operator rejected both.

**Why it was wrong:** `memory/feedback_luxury_direct_voice.md` explicitly lists
"House"/"the house" used to mean an agency or brand as a pattern to reject, along with poetic
fragments as headings. I had that memory available and did not consult it before writing copy.

**Rule for next time:** Before writing *any* user-facing copy for this repo — headings, taglines,
hero text, component defaults — re-read `memory/feedback_luxury_direct_voice.md` and
`docs/brand-positioning.md`. Direct, industry-standard luxury-travel language. Name the benefit,
name the brand, use the number. A heading that could appear in a poem is the wrong heading.

**Related:** the same file also bans "atelier", "dream vacation", "trip of a lifetime",
"quietly extraordinary", and dense literary verbs.

## 2026-11-04: Cruise sailing dates

**What happened:** I proposed the itinerary template with no dates, sending all date questions to the advisor. Nick corrected this: cruises book years in advance, so sailings must be shown through 2028.

**Why it was wrong:** I treated live availability (deferred) and published sailing dates (stable, and what a client plans around) as the same thing.

**Rule for next time:** Before cutting content from a travel page, ask how far ahead clients plan and book. Leave out what changes daily, such as prices and availability, not what they need in order to plan.

**Related:** when a user refers to "this", and no link or file came through, ask for it before designing around a guess.
