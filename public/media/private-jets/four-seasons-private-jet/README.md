# Four Seasons Private Jet - brochure image assets (batch 2)

Extracted from the 2028 travel-advisor brochures for Grand Horizons,
International Intrigue and New World Icons. Embedded resolution, no upscaling
or re-compression. Duplicates across brochures removed, and anything already
present in ../african-wonders/ was skipped.

Folders are named by itinerary stop, so they drop straight into the
itinerary cards on /private-jets/four-seasons-private-jet.

manifest-all.csv / .json list every file with dimensions, orientation and a
hero_capable flag. Each itinerary folder has its own README with its
hero-capable shortlist.

## Rights

Four Seasons / TCS World Travel marketing photography from the advisor
brochures. Standard advisor use. Keep property names accurate in captions
and alt text.
